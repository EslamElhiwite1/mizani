# مِيزاني

موقع ثابت بالعربي لتتبع الدخل والمصاريف والميزانية وأهداف الادخار بالجنيه المصري.

## ما يفعله

- تسجيل الدخل والمصاريف يدويًا مع الفئة والتاريخ والملاحظة.
- نظرة عامة على الرصيد ودخل ومصاريف الشهر ومعدل الادخار.
- حد شهري للمصاريف وحاسبة قاعدة 50/30/20.
- أهداف ادخار مع تقدم وتقدير تاريخ الوصول.
- تحليلات للتدفق النقدي وتوزيع المصاريف.
- تصدير CSV، ونسخة احتياطية JSON، واسترجاع JSON.
- لغة عربية أو إنجليزية، وسمة غامقة أو فاتحة.

## حدود مهمة

- لا يوجد backend ولا حسابات ولا ربط بنكي ولا تحريك أموال.
- البيانات تتحفظ في `localStorage` على متصفح الجهاز الحالي فقط.
- لا توجد مزامنة تلقائية بين الأجهزة. مسح بيانات المتصفح قد يحذف السجل، لذلك حمّل نسخة JSON دوريًا.
- تغيير العملة يغير طريقة عرض الرقم فقط ولا يحول القيم.

## التشغيل محليًا

افتح `index.html` مباشرة، أو شغّل خادمًا ثابتًا:

```bash
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## النشر على GitHub Pages

الملفات الجاهزة للنشر هي `index.html` و`styles.css` و`app.js`. ارفعها إلى جذر repository عام أو خاص مفعّل عليه Pages، مع إضافة ملف `.nojekyll` فارغ. لا ترفع أي نسخة احتياطية JSON تحتوي بياناتك.
